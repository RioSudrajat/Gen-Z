# Aset network dan wallet

Diambil 18 Oktober 2026. Logo ditampilkan sebagai gambar lokal tanpa perubahan bentuk atau warna. Nama/merek milik pemegang masing-masing; tampilan opsi tidak menyatakan endorsement.

- `solana.svg`: [Solana brand assets](https://solana.com/branding), [SVG resmi](https://solana.com/src/img/branding/solanaLogoMark.svg).
- `bnb.svg`: [BNB brand assets](https://www.bnbchain.org/en/brand-guidelines), [SVG simbol kuning](https://www.bnbchain.org/images/brand-guidelines/svg/BNB%20Chain_Symbol_Yellow.svg).
- `base.svg`: [Base brand kit](https://github.com/base/brand-kit), `logo/TheSquare/Digital/Base_square_blue.svg`. Square adalah aset resmi terbaru, berbeda dari lingkaran pada screenshot lama.
- `metamask.svg`, `rainbow.svg`, `coinbase.svg`: [RainbowKit, repository resmi Rainbow](https://github.com/rainbow-me/rainbowkit/tree/main/packages/rainbowkit/src/wallets/walletConnectors), file SVG pada direktori connector masing-masing. Lisensi MIT dipertahankan pada `RainbowKit-LICENSE`. Aset icon Coinbase berasal dari connector bernama coinbaseWallet; tidak menambah SDK atau dukungan vendor khusus.
- Wallet EIP-6963 lainnya memakai `connector.icon` dari metadata announcement. Provider tanpa icon memakai inisial nama, bukan logo buatan.
