# Audit after: seleksi Stack saat scroll

14 Oktober 2026. Mode after dipilih pengguna dalam sesi ini. Scope hanya bug layer aktif tanpa hover yang disengaja, pada `landing/src/NemesisStackSection.tsx`. Nomor temuan melanjutkan audit sebelumnya.

## Temuan

2. **MEDIUM, R-19 dan C-4: Layer 2 aktif sebelum ada interaksi.** `GenZStack` menginisialisasi `active` dengan `"depin"`, sehingga label Gen-Z Network terpilih dan tiga layer lainnya meredup saat section pertama kali muncul. Alasan: penekanan visual memberi kesan pengguna memilih layer, padahal belum ada input. Perbaikan: inisialisasi `active` dengan `null`, sehingga semua layer terlihat normal saat dibuka atau pertama kali dicapai lewat scroll.

3. **MEDIUM, R-19 dan C-4: scroll dengan kursor diam bisa memilih layer.** Handler `onPointerEnter` pada foundation, slab SVG, dan label langsung memanggil `onSelect` ketika pointer bertipe mouse. Browser juga mengirim event tersebut ketika elemen masuk di bawah kursor karena scroll. Alasan: highlight seharusnya membantu membaca layer yang sengaja ditunjuk, tetapi saat ini scroll saja dapat mengubah pilihan. Perbaikan: pusatkan pemilihan hover pada gerakan koordinat mouse yang benar-benar berubah, cegah pemilihan selama scroll, dan pertahankan klik/tap serta fokus keyboard. Uji lagi jalur pointer keluar agar seleksi hover tidak tertinggal.

## Reproduksi dan bukti

Server Vite lokal `http://127.0.0.1:5190/`, Chrome headless, viewport 1440 × 900. Script `landing/qa/stack-scroll-audit.mjs` tidak mengubah source aplikasi.

| Langkah | Hasil |
| --- | --- |
| Buka halaman tanpa menggerakkan mouse | `Gen-Z Network` memiliki `aria-pressed=true` |
| Scroll ke stack tanpa gerakan mouse | `Gen-Z Network` tetap terpilih |
| Gerakkan pointer masuk lalu keluar stage | Tidak ada label terpilih |
| Kembali ke atas, tempatkan kursor, lalu wheel-scroll hingga label Layer 2 berada di bawahnya | `Gen-Z Network` terpilih lagi |
| Event pada langkah terakhir | Satu `pointerenter` pada koordinat `(240, 450)`; tidak ada `pointermove` |
| Error JavaScript halaman | Tidak ada |

Bukti mentah: `landing/qa/stack-scroll-audit/evidence.json`. Screenshot: `landing/qa/stack-scroll-audit/initial-scroll.png`.

## Scope perbaikan dan pemeriksaan sesudahnya

Arah visual mengikuti implementasi Stack yang sudah ada: diagram isometrik putih/mint, ENERGY 2 / RHYTHM 2 / MOTION 2 sesuai `landing/qa/stack-refresh/NEMESIS-PORT.md`. Tidak diperlukan perubahan aset, layout, palette, atau copy. Tujuan penekanan visual adalah membantu pengguna membaca layer yang sengaja ditunjuk atau dipilih.

Setelah nomor disetujui: periksa state awal; scroll maju/mundur dengan kursor di luar dan di atas diagram/label; hover tiap layer dengan gerakan mouse; klik/tap; keyboard/focus; pointer keluar; viewport mobile; reduced motion; build produksi. Delivery Gate perbaikan belum dijalankan karena source belum diperbaiki. Laporan ini merupakan temuan bug, bukan klaim perbaikan sudah lulus.
