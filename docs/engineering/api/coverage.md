## Cakupan dan batas

Public marketing/legal/informational content dapat tetap file/SSR; tidak membutuhkan endpoint palsu. Full operator self-service, functional rewards/points/TGE, secondary trading, instant exit dan live enablement tidak ditambahkan. Logical operations dapat diimplementasikan bertahap; jumlah kontrak bukan kewajiban membangun portal/operator atau microservices baru.
