# Roadmap Gen-Z

**Baseline:** 18 Oktober 2026. Urutan berbasis dependency, tanpa tanggal delivery baru. Founder 2–4 jam/hari dan free-first hingga testnet. Status di bawah diperiksa pada source; laporan tes lama tetap bertanggal pada [history](history/README.md).

## Milestone dan syarat selesai

| Milestone | Status | Hasil dan exit criteria |
|---|---|---|
| M0 — scope dan validation kit | Dokumen baseline tersedia | PRD/requirements jelas, model hak dan sumber terpisah, dependency live tercatat; validasi stakeholder masih diperlukan |
| M1 — entry, auth dan inquiry | Sebagian | Astro + Next.js + SIWE/sesi tersedia; inquiry+reference+outbox, scoped admin, retry dan retensi belum dibuat. Selesai setelah M01–M04 yang relevan teruji |
| M2 — asset/evidence demo | Belum | Satu solar hybrid, tujuh tab/facts/blocks/review, dokumen privat; M05–M07/M10, draft dan akses sensitif terbukti |
| M3 — lifecycle simulated | Belum | IDRX/USDC quote/consent/net settle/allocation/portfolio/report/funded claim; M08–M13/M16–M17, exception dan reconciliation terbukti |
| M4 — testnet engineering | Fondasi login saja | Base Sepolia registry/test funding, reviewed escrow/token/distributor, indexer/finality/recovery; contract/lifecycle failure cases M14 teruji |
| M5 — controlled live pilot | Didefer; blocker eksternal | Actual parties/data, issuer/legal/countries, identity/custody/FX, payout/refund, mandate, security dan continuity; bukti M15 tersedia sebelum dana nyata |
| Beta/scale | Bersyarat | Ulang proyek setelah rights/reporting/collection/economics terbukti; SCF scale/ASEAN mengikuti review relevan |

MVP berarti M1–M3 sesuai acceptance, bukan sekadar login shell. M4 hanya test funds; tidak mengaktifkan dana nyata. M5 memerlukan persetujuan dan bukti aktual di luar keberhasilan software.

## Dependency implementasi berikutnya

1. Resource-scoped grants/authorization, inquiry persistence dan outbox/worker adapter.
2. Canonical asset/project/offering/terms/evidence, typed editorial serta publication review.
3. Fixture solar hybrid versioned dan satu sumber model/calculator/dataset.
4. Quote/consent/eligibility sandbox, net settlement, allocation/register/portfolio.
5. Reviewed report, collection/distribution funding, owner claim/receipt dan exception/reconciliation.
6. Uji seluruh flow demo, retensi dan akses; lanjut engineering review kontrak/indexer Base Sepolia.

API/IoT ditambahkan saat akses data feasible; monthly reviewed tetap fallback. Rewards/Points/Gen-Z Token informational; functional reward, TGE dan portal operator penuh tidak menjadi milestone pengisi scope.
